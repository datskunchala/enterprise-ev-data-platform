- `Enterprise_EV_Fleet_Intelligence_Report.pdf` — three-page PDF snapshot supplied by the project owner.

Use the PBIX for report development and the PDF for quick review. The screenshots represent the supplied report snapshot and may not reflect data refreshed after export.
